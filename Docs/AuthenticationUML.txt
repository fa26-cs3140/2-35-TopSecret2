The authentication class creates, verifies, and changes login credentials.
Credentials are stored as ciphered strings in the format "username:password" using the default cipher
All ciphering is handled by the Cipher class.

createCredentials checks for valid inputs (using isValidUsername and isValidPassword)
then writes the ciphered file with the credentials

verifyCredentials deciphers the existing credentials, and returns true if they match
with the inputted username and password, returning false for any missing files or errors/mismatches

changePassword replaces the existing credentials file with the new password. It's implementation in the UI
should require correct credentials to be entered twice before accessing the method.
