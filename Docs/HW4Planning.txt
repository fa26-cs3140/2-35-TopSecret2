How the System Will work:
    On startup:
    1) Check for credential file (.cip)
        If not found:
            prompt to create username and password, save it as a .cip, exit
        If found:
            Prompt for username and password, verify they are correct
            Pass to userInterface, which displays options:
                List missions
                    lists missions
                    reprints menu
                Search missions
                    Allows user to enter word or phrase
                    Searches mission database for said word or phrase
                    return either all matching missions or "no missions found" message
                    reprints menu
                Enter mission number
                    Returns file of entered number
                    reprints menu
                Change password
                   Has user enter password twice, validates
                   Updates password according to user entry
                Exit
                    exits program
                Loops until exit is selected
