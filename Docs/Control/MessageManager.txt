MessageManager is the controller class that is the gateway used to read
and write agent messages.

A DataStoreInterface is provided in the constructor.

Methods:
createMessage(Agent recipient, String contents) -> Message: creates a
message object and attempts to store it in the database. If successful,
the Message object is returned. Otherwise, a TopSecretException is thrown.

retrieveMessages(Agent agent) -> List<Message>: Provided an agent object,
this method returns a list of messages stored in the database that are
intended for that user. If unsuccessful, a TopSecretException is thrown.
