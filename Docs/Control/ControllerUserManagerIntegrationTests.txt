Controller UserManager integration tests
----------------------------------------
ControllerUserManagerIntegrationTest.hasUsersFalseOnFreshDatabase - fresh test database has no users
ControllerUserManagerIntegrationTest.hasUsersTrueAfterUserCreated - user created through the real UserManager shows up
ControllerUserManagerIntegrationTest.verifyLoginSucceedsWithRealUserManager - real password setup then good login verifies
ControllerUserManagerIntegrationTest.verifyLoginFailsWithWrongPassword - real password setup then wrong login fails
Notes: real SQLiteDataStore on a test database plus a real
UserManager behind the full Controller; access, audit, and
messages stay mocked. ciphers/key.txt must be on the test
classpath; credentials.cip is deleted before and after each
test.
The Controller is constructed with a mocked
SessionManager as its 6th argument.
Run: .\gradlew test --tests "control.ControllerUserManagerIntegrationTest" --console=plain
